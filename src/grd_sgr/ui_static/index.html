grd-smartgridready

Test an energy management system the way SmartGridready defines it: through the EID it declares, with the official CommHandler. The result is evidence, not a certification: only the SmartGridready association declares products.

The EMS under test

Load the EMS's EID, its SmartGridready product description. Its configuration values become the form below. Credentials stay with this tool and never come back to the browser: a secret field left blank keeps the value given before.

Evidence API — optional; needed for E4 and the console's journal
Reference meter — optional; F1 and F4 judge the effect against it

Compliance tests

The tool acts as the grid operator's flexibility manager and drives the EMS through its own EID. Each run produces an audit report: scope, method, every verdict with its clause and evidence, and what the run cannot prove.
